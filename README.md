## 🐱 About

**CypherHat** is a security-focused vault for passwords, API keys, recovery codes, and secure notes. One vault, available on **Web** and **Mobile**.

> 🚧 This project is under active development.

---

## ✨ Features

- 🔐 **Unified vault** for passwords, notes, API tokens, and credentials
- 📱 **Multi-device:** Web, Android, and iOS
- 🛡 **Security-first design:** strict per-user isolation and encrypted storage
- 📜 **Activity log** for security events and device access
